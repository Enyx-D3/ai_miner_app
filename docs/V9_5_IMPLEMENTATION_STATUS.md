## Still intentionally external

### Local Qwen runtime
The model contract is frozen to Qwen2.5-0.5B-Instruct GGUF Q4_K_M, but a production llama.cpp Flutter runtime is not bundled. A runtime/license decision is still required before implementing download/cache/load/inference self-test and injecting a real `MobileModelAdapter`.

### Live P2P environment
The mobile join/sync code is present. Production proof still requires the real Brain2 web signaling endpoint, STUN servers, TURN where required, and disconnect/reconnect/duplicate/revocation testing.

### Real semantic parity and production gates
A frozen corpus must still be run on web and mobile to compare canonical IDs, atom boundaries, Current Truth, Databox evidence, MRS traces, LifeWiki/Notebooks and `.B2M` restoration. Security, performance, long-duration and release gates remain real-device work.
